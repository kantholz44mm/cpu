\renewcommand{\abstractname}{Abstract}
\begin{abstract}
    \itshape
    In this work, a new 8 bit RISC computer is developed from first principles for educational purposes. The custom ``AVA'' instruction set architecture is first defined in terms of the programming interface, which is then converted into a block-level datapath. It is validated by creating a logic-gate-level implementation using the ``Digital'' simulation software. Additionally, an emulator is written in Rust. An assembler with support for labels, macros and pseudoinstructions is developed in order to translate human readable source code into executable programs. Exemplary programs are written to demonstrate key features of the architecture such as function calls, stack-based operations and recursion. These programs serve to validate the architecture's ability to perform meaningful computation. Finally, the gate-level implementation is translated into its hardware equivalent in the form of multiple interconnected PCBs, retaining modularity of design and manufacturing.
\end{abstract}
