\renewcommand{\abstractname}{Abstract}
\begin{abstract}
    \itshape
    In this work, a new 8 bit computer architecture is developed from scratch. Different approaches and design philosophies for such architectures are explored and discussed. The instruction set is also built from the ground up, drawing inspiration from existing architectures. The architecture is implemented in both software and hardware. There is a software simulation at the gate level as well as an emulator for automated testing. An assembler is developed in order to convert a human redable, low level assembly language into the native executable format. The hardware is constructed using multiple interconnected \acp{pcb}.
\end{abstract}
