\section{Hardware}

For this work, in addition to the logical design and gate-level design in a software simulation, a hardware implementation of the \ac{ava} \ac{isa} is developed. This piece of hardware is intended to be used for demonstrations on digital computing. This chapter describes the process of converting the purely digital design into corresponding hardware.
