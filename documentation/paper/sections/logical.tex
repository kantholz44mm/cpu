\section{Logical Design} \label{sec:implementation_logical}

After the detailed description of the \ac{isa}, logical design can begin. The logical design describes the inner workings of an implementation on a functional level. In this stage, the abstract \ac{isa} is divided up into functional units, which are then interconnected to transfer data. The inner workings of each module are abstracted away as they are not yet relevant. The purpose of this stage is to give a high-level overview of a potential implementation and to compartmentalize functionality and complexity. This helps with estimating the number, size and cost of a physical implementation. It also helps to visualize data paths and find inconsistencies in input/output data sizes for each module. Since each module can be largely thought of as a black box, this approach allows rapid prototyping and large changes at low cost and risk.
