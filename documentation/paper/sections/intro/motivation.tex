\subsection{Motivation}

Im Rahmen der Vorlesungen ``Digitaltechnik'' und ``Rechnerarchitektur'' wurden im Studium an der DHBW bereits wichtige Grundlagen für das Verständnis moderner digitaler Rechensysteme erlernt. Beide Vorlesungen können von einer anschaulichen Visualisierung der vermittelten Konzepte profitieren. In Digitaltechnik werden Grundlagen von digitalen Schaltungen vermittelt, wobei Rechnerarchitektur Prozessoren auf einem höheren Abstraktionslevel erklärt. Ein anschauliches Modell einer simplen CPU könnte eine hilfreiche Überbrückung zwischen den beiden Abstraktionslevels sein. Aus Sicht der Digitaltechnik sind einzelne Module der CPU interessant. Beispielsweise können Register oder einzelne arithmetische Operationen anhand weniger, kleiner Module erklärt werden. Aus Sicht der Rechnerarchitektur ist besonders die Zusammensetzung und der Verbund der Module relevant. Hierbei kann der Datenpfad oder die Kontrolllogik veranschaulicht werden. Beide Vorlesungen profitieren von einer Veranschaulichung der zeitlichen Abläufe innerhalb eines digitalen Systems. Weil die Implementierung auf Basis einzelner logischer Gatter stattfinden soll, ist die Optimierung der Anzahl dieser Komponenten die wichtigste Metrik beim Entwurf und der Implementierung der ISA.

Dieser Gedanke bildet den Kern der Motivation für diese Arbeit. Zudem bietet eine solche Aufgabenstellung ein enormes Lernpotential für den Studierenden. Sie behandelt ein breites Spektrum an technischen Themen, deren Grundlagen bereits erlernt wurden. Somit können diese technischen Grundlagen vertieft und selbstständig erweitert werden. Auch die Planung und Durchführung eines komplexen Projektes ist notwendig und bietet Möglichkeiten zur persönlichen Entwicklung.
