\section{Timing}

The operational speed of a \ac{cpu} is in part determined by how fast it is ``clocked''. Most designs have one or more clock signals, which instruct the device when to execute the next step of operation. This chapter explains the fundamental need for such clock signals, as well as how they are used within \acp{cpu}.

\subsection{Combinatorial and sequential logic}

Combinatorial logic describes a circuit of digital gates that compute some pure boolean function. This means that the output of the circuit depends only on the present input and not on the history of the input. This is in contrast with sequential logic, in which, as the name suggests, the output also depends on the order of operations, i.e an output may depend on previous inputs. In a digital electrical computer, this can be realised by forming loops between logic gates. An example of a combinatorial logic circuit is the \ac{alu}. There is no state stored within the \ac{alu}, it need not know the results of its previous operation to calculate an addition. Once the input signals have been applied and propagated through the logic circuit, the system is stable. There are no feedback loops that may cause the circuit to change state at any point. An example of a sequential logic circuit is the venerable register. It is a form of volatile memory, and must therefore store state. This can be accomplished by forming cycles between the logic gates. This has the advantage that it can create stable or unstable feedback loops, i.e memories and clock generators. However, it has the side effect that it cannot be fully analysed using boolean algebra anymore. To create useful memories, a mechanism is required to instruct such a device when it should load new data and when it should retain its contents. For this reason, memories must be clocked.

\subsection{Propagation}

Electrical signals, have a finite speed. Based on this alone, the input signals need some amount of time to propagate to the output signals. Furthermore, the electrical components used to implement logic gates have a non-zero propagation time, after which the output signal is guaranteed by the manufacturer to have reached the expected level. Since many of these individual logic gates are connected in series, their propagation delays add up, as do the propagation times of the traces between the circuits. The propagation times of logic gate \acp{ic} are typically on the order of 10 nanoseconds. The propagation times of the \ac{pcb} traces are negligible \todo{Source, Numbers}. All components that operate within the same time domain, i.e under the same clock signal, must be able to be fully propagated within each clock tick. If this is not the case, the correct result is not yet available when the next step starts. Therefore, the longest chain of delays determines the maximum clock rate that the \ac{cpu} can operate at.

\subsection{Clock signal}

The clock signal is an approximation of a square wave in most designs. Because only the time information is interesting, it is important to make the timing information as precise as possible. Due to the manufacturing tolerances of the components which are used to detect rising or falling edges, steeper clock signal edges are preferrable. When both falling and rising edges of a clock signal are used for instructing circuits with different propagation delays, the width of the HIGH and LOW signal phase may be asymmetrical to reflect this. This approach avoids unnecessary downtime but requires more complex signal generation logic.
