\section{Implementation}

In this chapter, a \ac{cpu} is implemented. Initially, the desired behavior of the device is described and written down in an \ac{isa} specification. Then, a logical design is created, capturing this specification. This logical implementation is then recreated in two different pieces of software in order to verify and validate the \ac{isa}. Afterwards, an electrical implementation is developed.
